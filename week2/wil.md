# 프론트엔드 스터디 WEEK 2
 이번 주차를 통해 html, css, js로만 웹사이트를 구현했을때 보다 react를 사용하는 것이 더 직관적이고 편하다는 것을 알게되었다.
 기존에 기능을 구현할때 <script>태그 안에서 코드를 작성하여 기능을 구현했을때는 개발자가 스스로 웹에서 어떻게 구현되는지 머리속으로만 생각해야했는데 react를 사용하니까 웹의 구조를 보면서 기능을 구현할 수 있어서 여러모로 효율적이라고 느꼈다.
 실제 인스타그램을 보면 한 게시물에 여러개의 사진을 넣을 수 있고, 각각의 사진마다 캡션이 달라지는 기능이 있어서, 이러한 기능을 구현해보고 싶었다. react에 익숙하지 않기에 어쩔 수 없이 GPT의 도움을 받아서 jsx를 수정해보았다. 코드를 직접보고 jsx에 적용해보니까 어떤 식으로 작동하는지 대강 알 수 있어서 사진마다 캡션이 바뀌는 것은 스스로 해보았다. import {useState} 의 기능을 몰라서 어떻게 돌아가는지는 알 수 없었지만 사진 소스나 string을 배열로 저장하여 사용할 수 있다는 것을 알았다.
 강의를 듣고 추가적인 궁금증을 가지고 직접 적용해 보는것까지가 더 알차게 gdg 스터디를 활용하는 것 같다.
