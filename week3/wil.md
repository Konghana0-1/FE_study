# 프론트엔드 스터디 WEEK 3
3주차에서는 React의 컴포넌트를 배웠다. React를 알기 전까지는 코드만 보고 화면을 머리속으로 구상하기 어려웠는데 Component의 개념을 배우고 난 뒤에는 코드만으로 어떻게 렌더링될지 알아보기 쉬웠다. 강의에서 코드를 타이핑하는 것 부터가 개발이 아니라 구상과 설계를 시작할 때부터 개발이라고 말씀하신것이 큰 깨달음을 주었다. 실습 코드에 배운 몇 가지만 적용하는 건데도 불구하고 설계 과정의 중요성을 깨달을 수 있었다. Component를 만들고 직접 적용해 보면서 게시물이 더 많아진다면 어떻게 해야지 효율적일지 생각하면서 과제를 진행하였다. map()을 활용하여 배열에 구별되는 정보들을 담아서 다른 게시물들을 렌더링하기 용이하였고, 각 기능별로 Component를 구성할 때 Props를 구조 분해 할당을 이용하여 필요한 정보만 이용하는것이 더 효율적인 코드인것 같다. 과제를 통해 추가적인 학습을 하면서 얻는것이 많다고 느껴졌다.
