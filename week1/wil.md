# 프론트엔드 1주차 wil
## HTML
HTML: Hyper Text Markup Language
HTML의 여러가지 태그들을 검색해보고 그 의미에 대해 더 파악해보았다.
예를들어 '<aside>', '<footer>' 같은 태그들의 쓰임도 알게되었다.
이러한 semantic 태그들이 직관적이고 쉽다는 느낌도 받았다. 
하지만 프론트엔드를 잘하기 위해서는 HTML의 모든 태그를 아는 것보다 JS를 더 잘 다뤄야 한다고 생각이 들었다.
## CSS
CSS: Cascading Style Sheets (계단식 스타일 시트) -> 계단식인 이유: 우선순위에 따라 위에서 아래로 적용되기 때문이다.
style을 적용하려고 할 때 HTML내부적으로 <style>을 써서 해도 되겠지만 태그가 많아지거나 웹사이트의 규모가 커지면 따로 css파일을 만들어서
link하는게 나을 것 같다. 유지보수 측면에서도 그러한 편이 더 낫다고 생각했다.
flexbox와 grid에 대해서는 꼭 숙지하고 있어야겠다.
HTML과 마찬가지로 모든 attribute와 그 값을 아는 것보다 JS를 더 잘 다루는게 중요하다고 생각이 들었다.
## JS
강의에서 JS에 대해서 굉장히 쉽게 설명해주셔서 이해하기 편했다. 실제로 우리가 윁사이트를 이용할떄 그저 감상하기보다는 어떤 걸 클릭하거나 입력할때가 많은데 이러한 측면에서 봤을때 DOM과 Event에 대해서는 깊게 알 필요가 있을 것 같다.
특히나 DOM의 트리구조를 이해하는 것과 Event 발생시에 어떤 반응을 할건지가 중요할 것 같다.
