# 프론트엔드 스터디 WEEK 5
홍익대학교 수업 사이트에서 과제 마감 기한을 확인하려고 과제 화면을 썼다. 과목 목록에서 과목을 하나 누르고, 과제란에 들어가서 해당 과제를 누르면 마감 기한과 제출란을 볼 수 있었다.
과제 목록에 '제출완료'나 '미제출'이 표시되어 있어서 제출 여부를 대략 알 수 있는 점은 편했다. 하지만 마감 기한을 보려면 과목마다 과목 → 학습활동 → 과제 순서로 하나씩 들어가야 해서, 과목이 많을수록 같은 동작을 반복해야 했다. 또 목록에 제출란을 한 더 확인하여 제출 여부를 알 수 있었다. 과제 하나의 정보는 정확히 알 수 있었지만, 지금 내야 할 과제들이 무엇이고 언제까지인지를 한눈에 보기는 어려웠다.
내가 만든다면 모든 과목의 과제를 한 화면에 모아 보여 주는 화면을 추가하고 싶다. 상위 컴포넌트에서 모든 과목의 과제 데이터를 배열로 받아 오고, 이를 제출 여부에 따라 나눈다. 미제출 과제는 마감 기한이 가까운 순으로 정렬해서 위에 보여 주고, 제출 완료한 과제는 하위에 따로 컴포넌트로 만든다. 각 목록에는 Props로 과제 정보를 넘기고 `map`으로 과제 카드를 렌더링한다. 제출 완료 목록은 `[showSubmitted, setShowSubmitted]` State로 접고 펼 수 있게 할 것 같다. 이렇게 하면 과목마다 들어가지 않아도 급한 과제부터 바로 확인할 수 있을 것 같다.
